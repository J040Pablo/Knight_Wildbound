==================================================
CHANGE MANIFEST — CONTROLLED VISUAL BASELINE (STANDARD SHADER)
==================================================

1. Root Cause of White Terrain Identified & Resolved
   - Root Cause 1: `GetDefaultTerrainMaterial()` in `ContinuousTerrainGenerator.cs` initialized the Standard material base albedo color to pure white (`mat.color = Color.white`). Standard built-in shader ignores mesh vertex colors and renders the material albedo (`Color.white`).
   - Root Cause 2: `BiomeRegionTrigger.cs` enabled dense atmospheric exponential fog (`RenderSettings.fog = true`, density `0.015f`), creating a bright white haze over distance.

2. Permanent Material Albedo Fix
   - Set terrain base albedo to Rich Green (`RGB: 0.25, 0.50, 0.22`, `Alpha: 1.0`) in `ContinuousTerrainGenerator.cs`.
   - Explicitly forced runtime terrain renderer material instances (`renderer.material`) to Standard shader with rich green color (`0.25, 0.50, 0.22`) and Metallic/Smoothness/Emission = 0 in `SceneEnvironmentBuilder.cs`.

3. Baseline Control Objects Created
   - Created `TerrainColorTest` (Cube with PURE RED `1,0,0` beside player spawn) to verify material lighting vs global pipeline.
   - Created `TreeColorTest` (Control tree: Trunk = Brown `0.463, 0.318, 0.227`, Leaves = Green `0.306, 0.580, 0.275`) using standard built-in materials.

4. Atmosphere & Environment Lighting Baseline
   - Directional Sun Light: Single light, Intensity = 0.8, Color = White, Soft Shadows = ON.
   - Ambient Light: Flat mode, Intensity = 0.5, Ambient Color = (0.45, 0.45, 0.45).
   - Fog: Disabled (`RenderSettings.fog = false`) across `SceneEnvironmentBuilder.cs` and `BiomeRegionTrigger.cs`.

5. Detailed Auditing & Tracing Added
   - Added `[BASELINE TERRAIN]` logs outputting Object, Shader, Color, Emission, Metallic, Smoothness.
   - Added `[MATERIAL TRACE]` logs.
   - Added `[COLOR DEBUG]` logs reporting active ColorSpace and HDR state.
   - Added `[FINAL MATERIAL COLOR]` audit confirming final material state after all initialization systems run.
